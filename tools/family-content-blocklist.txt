# DICTION DASH — family-content blocklist
#
# Every other invariant in this codebase is machine-gated: the approved-name
# cap, the Redline's exclusive red, the one-edit fake-collision guard. Word-bank
# content safety was the exception — pure hand curation, with nothing stopping a
# future addition from landing something the platform's general-audience rating
# will not carry. This file closes that gap.
#
# General-audience framing is a hard platform-eligibility requirement, and the
# check runs against BOTH the shipped bank and every misspelling the fake
# generator can reach from it — a mutation that lands on something ugly is the
# failure mode hand curation cannot see.
#
# FORMAT
#   exact <term>     the whole word must not equal this
#   part  <term>     the term must not appear anywhere inside a word
#   safe  <word>     a control: proves the `part` rules do not fire on it
#
# `part` is the dangerous kind — 'ass' inside 'class', 'grape', 'assess' is the
# classic false positive — so it is reserved for strings that cannot be
# innocent, and every one is proved against the `safe` controls below.
# Entries are lowercase a-z, one per line, sorted within a section.
