# WORD RUN approved audio

This directory carries the production-side audio layers referenced by
`manifest.json`.

Phase 4: every creature recording is replaced by procedurally rendered
signal-noise textures (`corruption_*` / `interference_*` WAVs, generated by
`node tools/generate-corruption-audio.mjs`, deterministic). The asset ids the
runtime schedules against are unchanged, so the RC9 layering, gain trims and
throttles all apply as before.

The procedural RC9 audio engine remains the authoritative fallback and timing
layer. Generated files are additive, replaceable, and gain-trimmed through
`manifest.json`.

Current policy:
- Keep procedural surface texture; a dedicated -2.9 dB trim applies in RC9.3.
- Threat positional timing remains driven by simulation state; long noise
  bodies are throttled so they do not smear Hunt cadence.
- Legacy organic layers (wind bed, impacts, landings, GO ignition) stay until
  the next audio pass decides their fate.
